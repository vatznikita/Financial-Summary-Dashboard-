# 💰 Financial Dashboard Analysis (Power BI)

This Power BI project presents an interactive financial dashboard built to analyze a company's global **sales and profit performance** across multiple countries, product lines, and business segments. The dashboard empowers stakeholders with a clear understanding of key metrics to drive strategic decisions.

---

## 📅 Project Timeline
**January 2025**

---

## 🔧 Data Preparation & Modeling

The dataset was processed and modeled within Power BI and Power Query with the following steps:

- Cleaned and transformed data using Power Query Editor  
- Created custom **calculated columns** and **measures** using DAX  
- Used aggregation functions like `SUM`, `AVERAGE`, and `MAX` to generate key KPIs  
- Established logical **data relationships** for seamless interaction across visuals

---

## 📊 Dashboard Visualizations

The dashboard provides a powerful snapshot of the financial landscape using engaging and informative visuals.

### 📈 Key Visual Elements

- 🎯 **KPI Cards** – Total Sales (123M), Total Profit (16.13M), Gross Sales (98M), Max Sales (1M), Avg. Sales (185.2)  
- 🌍 **Map Chart** – Sum of Profit by Country  
- 🍩 **Donut Chart** – Segment-wise sales distribution  
- 📉 **Line Chart** – Profit trends by Year, Quarter, and Month  
- 📊 **Bar Charts** – Product-wise and Region-wise Sales & Profit  
- 📆 **Slicer** – Date-based filtering for temporal analysis  

---

## 🌍 Key Insights

- **Government** and **Enterprise segments** led in overall revenue share  
- **North America** and **Europe** were top-performing regions  
- Products like **Paseo** and **VTT** dominated in both total sales and profit  
- Seasonal trends revealed peaks in profit during mid-2014 to early 2015  
- Flexible date slicers enable custom trend analysis and dynamic storytelling

---

## 🛠️ Tools Used

- 📊 **Power BI** – Visualization and report development  
- 🧹 **Power Query** – Data cleaning and transformation  
- 🧠 **DAX** – Calculated columns, custom KPIs, and measures  
- 🗺️ **Map Integration** – Geo-analysis for global sales performance
